# Прогон критериев приёмки — ТЗ раздел 11

Подготовка: выполнены `db/00…02`, через интерфейс созданы «ТЕСТ · УКС …» (все этапы) и «ТЕСТ · УРиП …» (часть этапов), затем `db/03_demo_data.sql`.
Колонка «БД» — проверено автотестом на копии базы (PostgreSQL 16, скрипты `db/`); остальное проверяется в браузере.
