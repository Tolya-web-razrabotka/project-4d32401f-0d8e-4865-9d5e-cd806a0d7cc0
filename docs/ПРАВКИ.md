**Детали реализации и меры против поломок:**

- **Размеры (1.1)** меняются одним скриптом по всем файлам `src/` (кроме `components/ui`) по таблице соответствия классов за один проход, чтобы замены не накладывались друг на друга (`text-lg` → `text-sm`, а не дважды). После — ручная проверка каркаса, таблиц, диалогов. Компоненты shadcn не трогаем — у них уже компактные размеры.
- **Вкладки** — одна общая пара классов в `src/lib/ui.ts` вместо пяти копий `TAB_CLASS`.
- **Статусы этапов** берут цвет из справочника (`stage_statuses.color`) — его по-прежнему настраивает админ; меняется только способ отрисовки (тон фона и затемнённый текст через `color-mix`, работает в Safari на iPad).
- **Подсветка** (раздел 8 ТЗ) сохраняется полностью: просрочено — красный тон, «горит» — жёлтый, «нет ответа» — красная рамка, «не назначен» — оранжевый. Меняются только оттенки.
- **Шрифт** подключается ссылкой в `<head>` с `display=swap`: если Google Fonts недоступен, остаётся системный шрифт, интерфейс не ломается.
- **Демо-данные** создаются через функции БД от имени администратора (`create_object`, копирование этапов с условиями и сценариями), поэтому структура такая же, как при работе через интерфейс. Даты считаются от «сегодня», чтобы подсветка была живой в любой день показа. Повторный запуск блокируется. Скрипт прогоняется на копии базы перед публикацией. Тестовые объекты «ТЕСТ · …» не трогаются; скрыть их — отдельный необязательный скрипт `db/05_hide_test_objects.sql`.
- **Проверка перед каждым коммитом**: синтаксис всех изменённых файлов, разрешение импортов, поиск оставшихся «·» и старых классов размеров.

## Развёртывание на сервере «Саня» (Beget), 22.10.2026

- Адрес: **https://lider.demo-2bstudio.ru** (поддомен демо-домена студии, A-запись → 155.212.221.123, сертификат Let's Encrypt до 20.01.2027, продлевается certbot автоматически). Порт 8100 закрыт. База — облачный Supabase, как в Lovable.
- Сервер общий (9 сайтов nginx на 80/443, Docker-проекты), поэтому «Лидер» стоит изолированно: `/opt/lider` (свой Node.js 22.12, код, сборка), служба `lider` на `127.0.0.1:3100`, nginx-сайт `/etc/nginx/sites-available/lider` (80 → 443, HTTPS дописал certbot; скрипт этот файл больше не перезаписывает). Чужие сайты проверены после установки — работают как прежде.
- Код забирается с GitHub ключом сервера `/root/.ssh/lider_deploy` (Deploy key «sanya-server», только чтение).
- Обновить после новых коммитов: `bash /opt/lider/app/deploy/deploy.sh update`. Подробно — `deploy/README.md`.
- **Особенность «Сани»:** порт 443 занят распределителем nginx `stream` (`/etc/nginx/stream-enabled/vpn-cascade-beget.conf`): по домену из TLS он отправляет запросы во внутренние порты, по умолчанию в `127.0.0.1:10444`. Поэтому HTTPS-блок сайта слушает `listen 127.0.0.1:10444 ssl proxy_protocol;`, как все соседние сайты, а не `listen 443 ssl`. Certbot по умолчанию пишет `listen 443 ssl` — после выпуска сертификата для нового домена эту строку надо заменить, иначе nginx не перечитает настройки (`bind() to 0.0.0.0:443 failed`) и не поднимется при перезапуске. Копия рабочего файла до правки: `/opt/lider/nginx-lider.bak`.
- Не делать на сервере: `apt upgrade`, `do-release-upgrade`, перезапуск nginx (только `reload`) — на нём работают чужие проекты.
