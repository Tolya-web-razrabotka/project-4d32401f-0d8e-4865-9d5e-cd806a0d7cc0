# База данных «Лидер» v1

Выполнять в Supabase → SQL Editor строго по порядку:

1. `00_lider_v1_migration.sql` — схема, RPC, представления, RLS, storage
2. `00b_lider_v1_seed_spravochniki.sql` — стартовые справочники
3. `01_after_migration.sql` — сотрудники, заказчики, закрытие `log_history` (подставить email пользователей)
4. `02_fixes.sql` — исправление tg_guard_status() (прямые изменения этапов и заявок падали) и запись загрузки файлов в историю
5. `03_demo_data.sql` — только для демо: «оживляет» объект «ТЕСТ · УКС …», созданный через интерфейс
6. `04_demo_data.sql` — демо-данные для показа заказчику: 6 объектов, ~30 заявок, история; нормативы этапов и ФИО сотрудников. Самостоятельный, от 03 не зависит, повторный запуск блокируется
7. `05_hide_test_objects.sql` — необязательно: скрыть объекты «ТЕСТ · …» (мягко, есть отмена)
8. `06_stage_template_files.sql` — **обязательно** с правки 2.3 (23.10.2026): файлы-образцы «От нас» / «Ждём» у этапов справочника — таблица `stage_template_files` и хранилище `lider-templates`. Ожидаемая проверка: `1 | 1 | 3`. Повторный запуск безопасен
9. `07_object_types.sql` — **обязательно** с правки 2.5 (23.10.2026): справочник «Типы объектов» (`object_types`), `objects.object_type` ссылается на него; «УКС» и «УРиП» заводятся автоматически, объекты не меняются. Ожидаемая проверка: `2 | 1 | 0`. Повторный запуск безопасен
10. `08_picket_range_field.sql` — **обязательно** с правки 2.10 (23.10.2026): тип поля заявки «Пикеты (от – до)»; все поля «Пикеты…» переводятся на него. Ожидаемая проверка: `9 | 0` (по одному полю на каждый вид заявки с пикетами). Повторный запуск безопасен
11. `09_textarea_field.sql` — **обязательно** с правки 2.11 (23.10.2026): тип поля заявки «Многострочный текст»; поля «Комментарий…» переводятся на него. Ожидаемая проверка: `10 | 0`. Повторный запуск безопасен
12. `10_request_statuses.sql` — **обязательно** с правки 2.14 (23.10.2026): справочник «Статусы заявки» (названия, текст кнопок и цвета шагов «Хода заявки»); `request_set_status()` пишет в историю название из справочника. Ожидаемая проверка: `5`. Повторный запуск безопасен, настроенные названия не перезаписывает

Схему не меняем через панель Supabase — только новыми файлами здесь, чтобы перенос на сервер заказчика был повторением этих скриптов.
